#### **Justificativa**

O Curso de Ciência da Computação promove atividades práticas por meio de metodologias que incentivam projetos dinâmicos, como jogos digitais. No entanto, muitos desses projetos ficam inacessíveis após a apresentação numa disciplina, projeto de pesquisa/extensão, sem uma forma eficaz de exposição permanente. A dificuldade em preparar ambientes para eventos limita o impacto dos trabalhos dos estudantes tanto para comunidade interna como externa.

O projeto DACC Station surge como uma oportunidade para conectar teoria e prática, preservando e exibindo os projetos desenvolvidos pelos discentes. Com a criação de um console de jogos que utiliza microcomputadores, modelagem 3D, eletrônica e desenvolvimento de jogos, o DACC Station oferece um ambiente de aprendizado colaborativo e acessível.

Nessa perspectiva, os discentes poderão estudar o ciclo de desenvolvimento de software, integrando conhecimentos em programação, sistemas operacionais e design de hardware. Essa experiência é essencial para uma formação completa, preparando-os para as demandas do mercado de trabalho, onde a integração entre hardware e software é cada vez mais exigida.

Logo, se faz necessário compreender os conceitos de Sistemas Operacionais, conjunto de operações, gerenciamento e compartilhamento de processamento e memória, sobreposição de janelas e interfaces, além de estudo sobre APIs e ferramentas de configuração do sistema.

**Objetivo Geral**

Integrar um console de jogos digital com hardware e software para gerenciar jogos/games desenvolvidos pelo Departamento Acadêmico de Ciências da Computação (DACC)

**Objetivos específicos**

- Desenvolver o sistema de configurações do console, permitindo ajustes como resolução, áudio, controles e conectividade.
- Integrar dispositivos periféricos, incluindo controles (USB e Bluetooth), sistema de som e outras interfaces de entrada e saída.
- Produzir relatórios técnicos detalhando o funcionamento dos componentes, testes realizados e possíveis otimizações.
- Estudar e documentar os protocolos e APIs necessárias para a integração eficiente dos periféricos e da interface gráfica.

**Atividades a serem desenvolvidas**

- **Estudo e levantamento teórico (PBL - Problem-Based Learning):** pesquisar e documentar protocolos e padrões de entrada e saída (ex.: HID para controles, ALSA/PulseAudio para som), explorar APIs e frameworks adequados para configurações do sistema (ex.: SDL2, Wayland/X11, BlueZ para Bluetooth) e analisar como outros sistemas similares lidam com configurações e integração de periféricos.
- **Desenvolvimento do sistema de configurações:** Criar um módulo de configurações acessível via interface gráfica, implementar suporte para ajustes como de vídeo, áudio, controles e redes, garantir a persistência das configurações no sistema de arquivos e registrar as decisões de design e implementação em um relatório técnico para futuras iterações e manutenção do sistema.
- **Integração de dispositivos periféricos:** Desenvolver drivers ou adaptar existentes para suportar controles USB/Bluetooth, integrar bibliotecas de áudio para garantir compatibilidade e qualidade sonora e criar testes de compatibilidade para diferentes modelos de dispositivos e gerar um relatório de testes, documentando modelos de periféricos testados, resultados obtidos e eventuais ajustes necessários para compatibilidade.
- **Produção de relatórios técnicos e documentação:** documentar protocolos e APIs utilizados para referência futura e produzir guias para desenvolvedores sobre como interagir com o sistema de configurações e os periféricos.

**Resultados esperados**

- Sistema de configurações completo e funcional , permitindo configurações intuitivas de resolução, áudio, controles e conectividade. A interface deverá oferecer suporte a diferentes dispositivos de entrada e saída, garantindo flexibilidade aos usuários e compatibilidade com diversos hardwares.
- Integração eficiente de periféricos , com reconhecimento automático de controles USB e Bluetooth, suporte a múltiplos dispositivos de áudio e implementação de interfaces para periféricos adicionais. Serão documentados os processos de detecção, configuração e otimização para garantir uma experiência fluida.
- Relatórios técnicos detalhados, contendo análises sobre o funcionamento dos componentes do sistema, testes realizados e otimizações aplicadas. Além disso, serão incluídos diagnósticos de desempenho e sugestões para melhorias futuras no software e na compatibilidade com hardware externo.
- Documentação completa sobre protocolos e APIs , abordando os métodos de integração dos periféricos e da interface gráfica. A documentação será estruturada para facilitar a compreensão dos desenvolvedores, incluindo orientações passo a passo, exemplos de código e explicação apresentada sobre a arquitetura utilizada.
